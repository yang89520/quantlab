全流派评分总览

扩展接口文档 · 如何新增一个技术流派

所有流派通过 QuantLab.registerStrategy(config) 注册，页面自动生成 Tab、图表叠加层、指标副图、评分与解读文案。新增流派只需追加一个配置对象，无需改动渲染引擎。

// 1) 注册一个流派（写在 strategies 段末尾即可）
QuantLab.registerStrategy({
  id: 'mystrategy',          // 唯一标识
  name: '我的流派',           // Tab 显示名
  color: '#A882FF',         // 主题色
  desc: '一句话说明',
  sub: 'rsi',               // 副图: macd/kdj/rsi/vol/obv/cci/adx/bias/boll/vr/cmf/turn/rs/fundmacd/mxslope/sho/pabar/ampstr/wyckoff/erm/none

  // 主图叠加：返回声明式指令数组，引擎负责绘制
  overlay: function (ctx) {
    return [
      { type:'hline', p:7.32, color:'#E8B84B', dash:[5,4], label:'警戒线' },
      { type:'line',  pts:[[10,6.8],[40,7.6]], color:'#4C8DFF' },
      { type:'rect',  x1:20, x2:60, p1:6.24, p2:8.62, fill:'rgba(232,184,75,.06)' },
      { type:'marker', i:80, p:8.02, text:'高点', color:'#F6465D', pos:'above' }
    ];
  },

  // 自动分析：返回 -100 ~ +100 的评分与结论
  analyze: function (ctx) {
    const s = ctx.last.c > ctx.ind.ma20[ctx.n - 1] ? 30 : -30;
    return {
      score: s,
      verdict: '一句话总结当前形态',
      points: [{ k:'读数', v:'具体数值' }]
    };
  }
});

可用绘制指令：line / hline / vline / rect / marker / label / area。 ctx 对象：ctx.data（全部K线）、ctx.ind（全部指标数组）、ctx.last（最后一根）、ctx.view（可视区间）、 ctx.isIndex（是否指数）、ctx.idxK（指数波动折算系数，个股恒为 1）、ctx.floatShares（流通股本，指数为 null）。

指数标的：指数与个股共用同一套流派，但 涨停板 / 龙头战法 / 情绪博弈 / 涨停回踩 20 / 换手率 依赖个股制度（涨跌停、连板、换手率、流通股本），在指数上会自动置灰并从综合评分中剔除。 写新流派时如果用到「涨幅 5% 算异动」这类绝对阈值，请乘 ctx.idxK，否则指数上几乎不会触发。

日线结构类：二买强势反击 的每个条件都按日线根数定义（5 日跌幅 / 150 根窗口 / 20 日均线），周月线上会置灰 —— 这类流派在 DAY_STRUCT 里登记，与依赖涨跌停制度的 DAY_ONLY 分开。

信号密度控制：ctx.helpers.vspan() 取可视区间 {lo, hi}； ctx.helpers.spread(items, px) 按像素间距稀释同类标记； ctx.helpers.pickMarks(cands, px, lastIdx) 做跨类避让并保证最新一根不被挤掉。 信号应覆盖 vspan() 的全部历史，不要写死「最近 N 根」。

综合评分由引擎按各流派 score 加权平均后再叠加「位置修正」自动得出，权重可在 QuantLab.WEIGHTS 中调整。

无头模式：QLMount(rows, { headless: true }) 不创建 Canvas，只装配指标与流派，返回 analyzeOne(id)。 选股器用它逐只计算候选池，与详情页共用同一份代码，因此评分必然一致。

服务端接口 · 自选股 / 分组 / 行情

自选股与分组通过 REST 接口读写，数据落盘在 data/store.json，服务重启后保留。行情由服务端代理公开行情源并做内存缓存（K 线 60s、快照 8s），前端不直连第三方。 数据源分三家自动降级：同花顺（前复权日线，带成交额）、新浪（全市场列表 / 备用 K 线）、腾讯（实时快照，带量比）。 东财接口当前不可用，已从主链路移除。

# 行情
GET    /api/stock/:code?bars=1200      // K线 + 周月线 + 基准 + 快照
GET    /api/stock/sh000001?all=1       // 指数全历史（约 20 年）
GET    /api/screen/market?node=all     // 全市场快照（5350 只，选股用）
POST   /api/screen/klines              // 候选池批量K线（≤300 只）
GET    /api/screen/meta                // 各数据源健康度
GET    /api/indices                    // 主要指数实时行情
GET    /api/snapshot?codes=600986,000977
GET    /api/search?q=浙文              // 代码/名称/拼音联想（含指数）

# 自选股
GET    /api/watchlist                 // 分组 + 股票 + 实时行情，一次拉全
POST   /api/watchlist                 // { code, groupId }
PATCH  /api/watchlist/:code           // { groupId } 移动分组
DELETE /api/watchlist/:code

# 分组
POST   /api/groups                    // { name }
PATCH  /api/groups/:id                // { name } 重命名
DELETE /api/groups/:id?moveTo=xxx     // 删除并把股票迁走
PUT    /api/groups/order              // { ids: [] } 排序

新增分组无需改代码：界面右上角 + 直接创建，data/store.json 中按 groups[] / items[] 结构存储，也可直接编辑文件后刷新。
