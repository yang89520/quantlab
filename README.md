# QuantLab · 多流派技术分析工作台

一个可在线访问的股票与指数技术分析服务：39 套技术流派图表可切换（含金坑战法、肉肉战法、涨停板、龙头战法、缺口、周线共振、唐奇安通道、一目均衡、相对强弱等 A 股实战体系），K 线支持日/周/月三周期，个股与大盘指数共用同一套指标与评分，自选股支持分组管理，另有一个覆盖全市场 5500+ 只的选股器（行情筛选 + 全池形态扫描 + 全量流派精算），所有评分与结论由算法实时计算，数据全部来自公开行情接口。

此外还有**今日一页**（`/today`）：每天只回答四个问题——现在市场怎么样、昨天我判对没有、明天可能怎么走、哪里缺数据。它背后是一套「预判 → 次日对账 → 归因 → 累计命中率」的闭环，让人能验证自己的判断，而不只是看指标。

## 本地运行

```bash
cd stock-lab
npm install
npm start          # 默认 http://localhost:3000
PORT=8080 npm start
```

依赖只有 `express` 与 `@duckdb/node-api`（自有业务库），其余全部手写（Canvas K 线渲染、指标算法、流派插件系统、GBK 解码、gzip）。
DuckDB 驱动装不上时，存储层会自动降级到 JSONL（`config.storage.engine`），全功能仍可跑通。
三期公式引擎需要独立 Python 环境：`python3 -m venv py/.venv && py/.venv/bin/pip install -r py/requirements.txt`（仅 numpy）。
Python 不可用时三期功能整体不可用，但一、二期与服务启动照常（`/api/health` 的 `python` 字段会报告原因）。

## 个人投研工作台：预判 → 对账 → 归因

这是本项目的核心机制。它不做预测优化，只做一件之前没做过的事：**把判断变成可被记录、可被验证的对象**。
四期已全部上线：今日一页（七格）、观察池、策略实验室，加上原有的分析台与选股器两个工具页。

### 跑一次

```bash
npm run daily                        # 收盘后完整闭环
npm run report                       # 判断力报告（命中率 / 分状态 / 错因分布）
npm run sector                       # 板块强度人读报告
npm run sector -- --capture          # 重新采集板块数据后出报告
node tools/daily-close.js --skip-sector   # 用已有板块榜重跑，省一次全量采集
```

`daily` 顺序固定不可调换：**交易日/指数K线/快照 → 板块强度 → 对账 → 预判 → 观察池推进 → 信号回填与自动降级 → 摘要**。
板块强度必须排在对账之前：`direction` 归因需要目标日板块榜；对账必须排在预判之前：先生成新预判会覆盖上下文。

### 每天落什么

| 落盘内容 | 用途 |
|---|---|
| `snapshot` 表（每只标的每天一行） | 次日对账的唯一基准 |
| `prediction` 表（预判卡） | 环境三态 + 评分拆解 + 失效条件 + 三情景 + 候选 + `mainline` |
| `reconcile` 表（对账结果） | 命中/未命中 + 四段归因 + 判断得分 |
| `sector_member` / `sector_strength` | 板块成分与四因子强度（行业/概念分榜） |
| `strategy_signal` / `strategy_gate` | 策略信号 T+1/5/10 跟踪、五道闸验证档案 |
| `data/watchpool/` / `data/strategies/` | Web 可写数据（JSONL，避开 DuckDB 单写进程锁） |

### 归因优先级（写死，不许并行）

```
环境错 → env         环境错了就不该怪选股：环境错时选股再好也是逆势
方向错 → direction   判对了环境但押错板块，不能去怪选股（二期）
标的错 → candidate   环境与方向都对，选股还亏才是选股逻辑问题
时机错 → timing      都对但当天冲高回落
```

顺序颠倒是归因分析最常见的错误——会让人一直去优化选股，而问题其实在环境或方向判断。

### 三条硬规矩

- **不填假数据**：拿不到就显示「需 X 功能」或空态，**绝不显示 0**（0 是有效值，会让人以为真的没有）
- **不打偷偷降级**：数据不完整时顶部状态条变黄、结论变灰但仍展示；板块资金因子缺失标 `degraded` 并给原因
- **当日必须实时**：本地库只到 T-1，请求当日强制走网络。拿昨天数据冒充今天是最危险的假数据形态

## 选股器（`/screen.html`）

全市场选股，**没有任何模拟或造出来的数据**：行情来自公开接口的全市场快照，技术形态与流派评分来自逐只拉取的真实 K 线。

### 三层结构

| 层 | 覆盖 | 数据 | 耗时 |
|---|---|---|---|
| 行情条件 | 当前股票池（主板 3192 只 / 全市场 5576 只） | 一次全市场快照，本地过滤 | 毫秒级，输入即生效 |
| 形态 | **池内每一只**，不截断 | 每只 260 根真实日线，服务端判定，当日落盘 | 主板首轮约 2 分 50 秒，之后秒回 |
| 流派 | **形态命中的全部标的**，不截断 | 逐只 1200 日线 + 260 周线 + 130 月线，`QLMount(headless)` 评分 | 约 0.27 秒/只（6 并发），338 只约 90 秒 |

第一层用到的字段：现价、涨跌幅、成交额、换手率、振幅、流通市值、PE、PB、距涨停幅度（按板块 10% / 20% / 30% 与 ST 5% 推算）。这些都能从全市场快照直接拿到，所以调整条件不需要重新请求上游。

第二层是**全池形态扫描**。形态判定（均线多头 / 站上 20 日线 / 20 日线上行 / 放量 / 60 日新高 / 5 日涨幅 / 年内位置）只需要尾部窗口：MA60 要 60 根、年内位置要 250 根，所以每只取 260 根就够，成本约为完整精算的 1/5。算法放在 `public/js/shape.js`，浏览器与服务端 `require` 的是**同一份代码**，不会出现「扫描说多头、精算说不是」。扫描结果按交易日缓存在 `data/shape-cache.json`，换行情条件、换流派、刷新页面都不重扫。

第三层对命中的标的逐只拉 1200 根日线 + 260 根周线 + 130 根月线 + 上证基准，交给与详情页**同一份** `QLMount(headless)` 计算，**不设 TopN、不抽样**。选股页不重写任何指标或判断逻辑，因此同一只股票在选股结果和详情页里的评分必然一致（实测 4 个流派 × 12 只标的零差异；分批精算与一次性精算逐只比对同样零差异）。

> 之所以把形态单独拆成一层：形态只能靠 K 线判定，如果跟着流派精算一起做，就只能覆盖 TopN 那一百多只，主板三千多只里绝大多数根本没被看过。拆开之后，扫描是「每只都看一眼」，精算只花在形态合格的标的上。

### 无头模式

`QLMount(rows, { headless: true })` 用一份「哑图表」替换 Canvas 引擎：`viewStart / viewCount / bw()` 给固定值，`setData / setOverlay / render` 变空函数。指标装配、金坑与肉肉的中间量、综合评分全部照常运行，返回 `analyzeOne(sid)` 供选股页调用。

### 一致性的三个前提

评分对「拿到的历史长度」很敏感，所以做了三件事，否则同一只票会算出不同分数：

1. **固定长度**：选股与详情页都用 1200 根日线（详情页默认视图）。
2. **补齐当日**：同花顺 `last.js` 收盘后仍停在 T-1，当日数据单独取 `today.js`，否则选股用的是昨天收盘、详情页是今天。
3. **冗余拉取**：按年拉取时多要一年，根数不足再补拉（上游偶发限流会少给一年，少 242 根就足以让「金坑」这类含历史统计的流派差出 20 分）。

## 指数

个股与指数共用同一套指标、流派与评分，但有 5 处必须区别对待，否则结论会错得很自然。

### 代码空间冲突

`000001` 同时是上证指数（沪）和平安银行（深）。因此指数一律用 **市场前缀 + 6 位** 作为唯一键：

| 标的 | 存储/路由键 | 展示 |
|---|---|---|
| 浙文互联 | `600986` | 600986.SH |
| 上证指数 | `sh000001` | 000001.SH |
| 创业板指 | `sz399006` | 399006.SZ |
| 北证50 | `bj899050` | 899050.BJ |

识别规则：沪 `000xxx`、深 `399xxx`、北证 `899xxx` 为指数段，个股不会落在这些段里。`normalize()` 返回 `asset: 'index' | 'stock'` 与 `key`，服务端一律用 `key` 请求上游（裸 6 位会在 `normalize` 里被当成深市个股 —— 这是踩过的坑）。

### 入口

- 侧栏「大盘指数」常驻 6 个主要指数（上证 / 深成 / 创业板 / 沪深300 / 科创50 / 中证500），点「全部」可看 9 个；
- 搜索框输入「上证」「沪深」或指数代码，结果带「指」标记，可直接加入自选分组；
- 手机端指数条为单行横滑，展开自选股即可看到。

### 5 个流派在指数上不适用

`涨停板 / 龙头战法 / 情绪博弈 / 涨停回踩 20 / 换手率` 依赖个股制度（涨跌停幅度、连板、换手率、流通股本）。指数没有这些字段，标签置灰、副图关闭、**并从综合评分中剔除**（权重按剩余 30 个流派重新归一），评分总览里显示「不适用」。周/月线上的 `涨停板 / 龙头战法 / 情绪博弈` 同理。

换手率一律由 `成交量(手) × 100 / floatShares` 现算，分子股本源自 `/api/stock` 行情快照，**不写死任何标的的股本**。个股快照偶尔拿不到 `floatShares`（北交所个别标的、上游字段缺失），此时 `量价理论 / 情绪博弈` 的换手那一条降级为「已跳过」、`换手率` 流派整体返回 0 分并说明原因，不会产生 NaN，也不影响其余流派评分。

### 指标口径的三处修正

1. **波动折算系数 `idxK`**：金坑战法「涨幅 >5% 算异动」、肉肉战法「>3.5%」这类绝对阈值是给个股写的。指数日波动只有个股的 1/3（上证中位数约 0.5%，创业板约 1.1%），直接套用几乎永不触发。因此按 `idxK = 指数 60 日涨幅中位数 / 1.9%`（钳制 0.2~1）折算阈值：上证约 0.23、沪深300 约 0.31、创业板与北证约 0.72。个股 `idxK = 1`，口径完全不变。
2. **VWAP**：指数的 `成交额 / 成交量` 得到的是成分股平均股价（约 15 元），不是指数点位（3600 点）。所以指数在研究振幅强度时退回「典型价」口径，资金 MACD 的累计均价改用 500 根滚动窗口（从 1990 年累计到今天，均价早就成了一条直线）。
3. **基准**：个股比上证指数；指数比沪深300（看沪深300 本身时退回上证），这样「创业板指 vs 沪深300」的相对强弱才有意义。

### 指数没有的量

顶部指标从「换手率 / 流通市值」切换为「成交额 / 当日振幅」；盘面诊断的情绪温度改用「量能相对 20 日均量 + 当期涨跌幅」，风险等级的 ATR 阈值按 2.4% / 1.6% 折算（个股是 6% / 4%）；操作建议给的是 ETF / 期指仓位区间，不再提「单票仓位」。

## K 线周期

### 取多少根

| 周期 | 默认显示 | 「全部」 | 实际上限 |
|---|---|---|---|
| 日 | 140（手机 60） | 2500 | 约 2512 根 ≈ 10 年 |
| 周 | 跟随上次选择 | 520 | 约 520 根 ≈ 10 年 |
| 月 | 跟随上次选择 | 125 | 约 125 根 ≈ 10.4 年 |

2500 这个数字不是自己定的：同花顺的年份文件只回溯到 10 年前，再往上要年份文件也没有内容，所以接口给 3000 也只会返回 2512 根。周线由日线聚合、月线由周线聚合，长度天然受日线约束 —— 日线给满，周月自动跟上。

根数按钮是 **90 / 250 / 500 / 全部**：切股票沿用上次选择，切周期不重置（避免按钮高亮和实际显示不符）。手机端以前把这一整组藏起来了，只剩 90 根看三个月、想拉长历史没有入口，现在放开。

工具栏可切换 **日 / 周 / 月**，切换后指标、形态、评分全部按新周期重算（不是简单重采样显示）：

- 波动率、换手率按时间平方根归一到日度量级，风险分级阈值才不会因周期变化而失真。
- 上证基准取 1500 根日线做日期前向对齐，周/月线的周期末日期也能拿到对应点位。
- **涨停板 / 龙头战法 / 情绪博弈** 依赖涨跌停幅度与连板，周/月线上没有意义，切换到非日线周期时这几个 Tab 会置灰并给出提示。
- **金坑战法** 的启动信号（游资进场、财神来敲门、跃坑、金K底）是日线口径（涨幅 5%~8%、上影 <1%），周/月线只展示金线王与位置结构，评分按 40% 折算。
- **肉肉战法** 的斜率均线 MX 与拐点压力位是纯价格衍生量，三个周期都成立；只有「反包启动」是日线口径（涨幅 >4%、量创 20 根新高），非日线不画该标记，评分按 45% 折算。

## 肉肉战法（斜率均线体系）

来源是通达信主图「均线斜率买卖信号 + 肉肉大肉」，核心是一条**斜率均线**而不是价格均线：

```
MX  = EMA(SLOPE(C,21) × 20 + C, 42)
MR  = SLOPE(MX, 2)          // MX 的 2 日斜率
MRR = REF(MX, BARSLAST(CROSS(0, MR)))   // 本次向上拐点的 MX 值
MN3 = HHV(MRR, 89)                       // 近 89 根所有拐点中最高的那个 = 动态压力
```

`SLOPE(C,21) × 20` 相当于把当日斜率线性外推 20 根，加到收盘价上再做 42 日 EMA。
效果是**价格还在横盘、趋势刚开始加速时这条线就先抬头**，比普通均线早半拍；代价是它比价格更“贵”，
下跌趋势中会一直压在价格上方。

体系内的买卖规则：

| 信号 | 条件 | 含义 |
|---|---|---|
| 底部首破 | `CROSS(MX, MN3)` 且 `MX/MFT<1.25`、`MX/LLV(MX,55)<1.35` | 底部第一次突破，两个倍数限制确保「还没涨多」 |
| 有肉肉 | `CROSS(MX, MRR)` 且 `MX/LLV(MX,55)<1.35` | 拐点之上重新走强 |
| 大肉 | `CROSS(C, MN3)` 且涨幅 >3.5%、`MX/REF(MX,1)>1.004` | 价格突破压力且趋势同步加速 |
| 闪，不好吃 | 突破后 5 根内 MR 又拐头向上 | 说明中间已经掉头一次，突破没延续 |
| 当心大面 | `MX/MRR>=1.55` 且日涨 >3.4% 且斜率由升转降 | 涨过头后的最后一冲 |

**对原文的三处修正：**

1. `DRAWTEXT(CROSS(C,MN3)&&C1>1.035,L*0.98,'大肉')&&MXR>1.004` 是语法错误（`DRAWTEXT()` 后接 `&&`），
   按语义拆成「画标记」+「AND MXR>1.004」两个独立条件。
2. `IF(MX>MRR&&MXR>1.004,MX,DRAWNULL),LINETHICK3,COLORGREEN,COLORRED` 连写两个颜色，通达信只认最后一个，
   等于永远画红色。这里按「趋势向上画金色、否则不画」实现，不再出现自相矛盾的着色。
3. `X_26: CAPITAL<6000000` 硬性要求流通盘 <6 亿股，会把中大市值股全部排除。这里**不做硬过滤**，
   只在解读里提示盘子大小，否则用户点开任何一只蓝筹都只能看到「不符合」，失去分析意义。

「反包启动」那一长串（X_1~X_29）合并成一个信号：前 5 根里 4 根阴线 → 突然爆量反包、上穿 6 日线、
MACD 柱缩短后重新放大、收在最高价 97.5% 以上。原文用 `REF(…,116)` 隐含「上市不足 116 根不出信号」，这里显式写成 `i >= 116`。

## 简谐振荡（Simple Harmony · SHO）

来源：Akram El Sherbini《Time Cycle Oscillators》，IFTA Journal 2018。作者把价格波动看作简谐运动
`y = A·sin(ωt)`，由 `a = -ω²x` 反推周期 `T ∝ √|位移/加速度|`，用周期的伸缩衡量多空动量。曾在
Futures Truth 的「多市场交易策略」跟踪中进入前 10（笔记里说的「全球第八」即指此）。

```
vt  = C - REF(C,1)                    // 速度（涨跌额）
at  = vt - REF(vt,1)                  // 加速度（涨跌额的差分）
a   = EMA(at, 14)
Tt  = SQRT(ABS(vt / a))               // 周期（恒正）
Ti  = IF(C > REF(C,1), Tt, -Tt)       // 带方向的周期
SHO = EMA(Ti,14) / EMA(Tt,14) × 100   // 归一化到 -100 ~ +100
SHI = EMA(Ti,14)                       // 简谐指数，未归一化
```

由于 `|Ti| = Tt` 且 EMA 是线性算子，`|EMA(Ti)| ≤ EMA(Tt)`，所以比值天然落在 ±100 内。
`Tt` 是无量纲的相对周期（缺了 2π 与比例常数），数值通常在 1~6 之间，**不能当作真实根数**读；
SHI 抬升只说明「当前波段周期变长、趋势更持久」。

**原文的判定体系：**

| 层 | 规则 | 含义 |
|---|---|---|
| 环境过滤 | `C > 50EMA` 且 `ADX > 18` → 上行；`C < 50EMA` 且 `ADX > 18` → 下行；`ADX ≤ 18` → 震荡 | 趋势里只用中心穿越，震荡里才用 ±40 边界做反转 |
| 主信号 | SHO 上穿 0 / 下穿 0 | 多空周期动量换手 |
| 常规阈值 | ±40 | 震荡市的超买超卖边界 |
| 极端阈值 | ±60 | 周期极端失衡，趋势动能衰竭（原文称实盘很少触及） |
| 离场 | 反向穿 0 / 触及 ±60 / 收盘破 50EMA / 斐波那契 38.2%·61.8% 或 ATR 倍数目标 | 四条并列，任一触发即了结 |
| 风控 | 信号 K 线极值外侧 1~2 倍 ATR；浮盈 1R 后转 ATR 跟踪 | 主图画出「多单/空单保护」虚线 |

**为 A 股做的三处适配：**

1. 原文是双向市场，这里把「空头信号」表述为减仓/回避，不提示做空。
2. 0 轴穿越要求**下一根仍留在同侧**才标注，滤掉 SHO 在 0 轴附近反复摩擦的锯齿（原文未提，但实盘噪声明显）。
3. ±60 只认「从 45 以内快速冲出」的那一次，避免在 60 附近来回穿越时刷出一堆「动能衰竭」。

## 价格行为（Price Action · Al Brooks）

来源：Al Brooks《Trading Price Action》三部曲。体系的核心不是指标，而是**先定环境、再找架构、最后等信号**：

| 步骤 | 问题 | 本实现的判据 |
|---|---|---|
| ① 向左看 | 现在是谁在主导？ | 20EMA 上方 K 线占比、10 根均线斜率（ATR 归一）、相邻 K 线重叠度 |
| ② 中间找 | 我为什么在这里进？ | L1/L2/L3、H1/H2/H3、双顶双底、楔形三推、失败突破 |
| ③ 向右等 | 什么时候扣扳机？ | 信号 K 线实体占比与收盘位置，止损放信号 K 线外侧 |

环境只有三种，策略完全不同：

```
up   : 均线上方占比 ≥ 62% 且 10 根斜率 > +0.25 ATR   → 追突破 / 浅回调买
down : 均线上方占比 ≤ 38% 且 10 根斜率 < -0.25 ATR   → 只找 H1/H2 卖点
range: 其余                                          → 下沿买、上沿卖、中部不动
```

**「数 K 线」的量化口径**（原文靠肉眼数，这里固定成状态机，保证可复现）：

```
回调开始：低点与收盘同时下移，且前一根收在 20EMA 同侧
一推   ：回调中出现新低，且中间必须有过反弹（高点抬高）
         —— 否则连续阴线会被误数成 L3、L4
触发   ：某根 K 线高点越过「信号 K 线」高点且收红 → L{n} 成立
信号 K 线：回调末端的阴线且收盘落在区间下半部
```

`L2` / `H2` 是原文的首选入场点（双底牛旗 / 双顶熊旗），评分权重是 L1 的两倍多。

**形态与规则：**

| 概念 | 判定 | 权重 |
|---|---|---|
| 20 缺口 | 连续 20 根不触碰 20EMA，极端强势/弱势 | ±10 |
| 双顶 / 双底 | 两高点价差 < 0.4 ATR、间距 5~30 根、中间回撤 > 0.7 ATR | ±10（在区间边缘时） |
| 楔形三推 | 三个递进极点，第三段幅度 < 第二段的 75% | ±8 |
| 失败突破 | 破 20 根新高/新低后 3 根内收回 | ∓6 / ±8 |
| 量度移动 | 区间内看对侧沿；突破后才用箱体高度投影 | — |
| 盈亏比 | 止损 = 信号 K 线外侧 0.25 ATR，不足 2R 放弃 | — |

**为 A 股做的适配：**

1. 不能做空，H 系列不提示开空，改写为「减仓参考位」。
2. 当日接近涨停时信号降权，因为实际买不进。
3. 20 根箱体高度超过股价 15% 时判为宽幅震荡，不再给量度目标（否则会投出 ±30% 这种没有操作意义的数字）。

## 涨停回踩 20 日线（二次启动）

来源：公众号「桔子写指标」2026-11-10 的通达信选股公式。核心思路是**只做强势股的第二次启动**：
先确认资金来过（涨停），再确认波动重新放大（振幅突破），再确认动能增强（涨幅加速），
最后等它回踩 20EMA 且当日重新放量上攻（涨超 3%），同时排除已经过热的形态。

原文六重条件与实现口径：

| 条件 | 原文 | 实现 |
|---|---|---|
| 涨停基因 | `C/REF(C,1)>1.09 AND C=H`，15 日内出现过 | 按板块涨停线判定（主板 10%/双创 20%/ST 5%/北交所 30%）且收盘=最高，15 日内、不含当日 |
| 振幅突破 | `振幅强度 := (振幅幅度+价格偏离)/均价*50`，`CROSS(…,3)` | 均价用 `成交额/(成交量×100)` 还原真实 VWAP；振幅幅度取最高/最低对均价的最大偏离，价格偏离取 K 线中点对均价的偏离 |
| 涨幅加速 | `C/REF(C,1)-1 > 预期振幅 AND MA(C,20)>REF(MA(C,20),1)`，5 日内出现过 | 统一成百分数后比较；预期振幅 = `2×前日振幅 − 前前日振幅` |
| 回踩 20EMA | `L<=EMA(C,20)` | 最低价触及或跌破 20EMA |
| 当日确认 | `C/REF(C,1)>1.03 AND C>O` | 涨幅 >3% 且收阳 |
| 过热过滤 | `REF(COUNT(C>O,3)>=3,1)=0`、`COUNT(O=H,5)=0` | 昨日之前无三连阳；近 5 日无「开盘价=最高价」 |

> **原文的量纲缺陷**：`C/REF(C,1)-1` 在通达信返回的是小数（涨 5% 得 `0.05`），而 `预期振幅`
> 是由 `(H-L)/L*100` 算出的百分数（`5.0`）。`0.05 > 5` 恒不成立，导致「涨幅加速」永远为假、
> 「五日有加速」永远为假，**原公式直接选股结果为空**。本实现统一乘 100 转成百分数。

另外两处按 A 股制度做了修正：涨停判定不再写死 9%，否则创业板涨 11% 会被误判为涨停、
真涨停（20%）反而在 `C=H` 不成立时漏掉；`COUNT(O=H,5)=0` 原文注释叫「无上影线」，
实际过滤的是「高开即最高、全天走低」的出货形态，文档按代码语义表述。

**评分构成**：涨停基因 +10（5 日内 +4）、振幅强度 +8（突破当日再 +6）、五日加速 +8、
回踩收回 +12（破位 −12）、20EMA 方向 ±5/−8、当日涨 3% +8、六重同日成立 +35（3 日内 +22）、
过热形态 −10/−8、离均线超 15% −10、无涨停基因 −15。

新增副图「振幅强度」：`min=0`，红虚线为 3 的突破阈值（约等于 K 线偏离成交均价 6%）。
预期振幅量纲不同（可为负），不放在同一坐标系，只在文字解读里对比。

## 二买强势反击（五日急跌后）

来源：公众号「桔子写指标」《把二买做稳做精，一个指标可以帮你》（2026-11-11）。原文明说这套指标
「不追求抓每一次反弹」，而是先用七道门槛把二买最常见的两种误判挡掉：

- **把弱势反弹当二买** —— 刚涨一点就追，其实股价根本没回到压力区；
- **把高位加速当二买** —— 看似突破，其实已在前高压力区末端。

对应的解法是「先确认抛压释放，再要求反弹没透支，最后等放量共振收复均线」。

| 条件 | 原文 | 实现 |
|---|---|---|
| 五日急跌 | `(REF(C,5)-C)/REF(C,5)*100>5`，`FILTER(…,10)` | 5 日累计跌 >5%；同一结构 10 根内只认第一次 |
| 结构有效期 | `JJD<150`（`BARSLAST`） | 距最近一次急跌 <150 根 |
| 贴近前高 | `(O-JDQG)/JDQG*100<10` | 前高 = 急跌信号根及之前两根的最高价；开盘距它 <10% |
| 反弹未透支 | `(C-LLV(L,JJD))/LLV(L,JJD)*100<50` | 距急跌以来最低点反弹 <50% |
| 短期没涨过头 | `(C-REF(O,5))/REF(O,5)*100<8` | 5 日涨幅（相对 5 日前**开盘价**）<8% |
| 放量确认 | `V>REF(V,1)*1.5` | 量 > 前一日 1.5 倍 |
| 均线共振 | `CROSS(C,MA5) AND CROSS(C,MA10) AND CROSS(C,MA20) AND MA20>REF(MA20,1)` | 昨收在三线下方、今收在三线上方，且 20 日线向上 |
| 当日确认 | `(C-REF(C,1))/REF(C,1)*100>3` | 当日涨幅 >3% |

> **三处原文问题**，实现时分别处理：
> ① 文中写「五周涨幅不超过 8%」，但代码是 `REF(O,5)`，是**五日**不是五周，按代码实现。
> ② `LLV(L,JJD)` 在 `JJD=0`（急跌当天就反包）时，通达信会退化成**全历史**最低价，`FBWDG`
> 因此必然不成立。本实现直接排除 `JJD=0`，效果一致且不会误用陈年低点。
> ③ 文末建议公式命名为「涨停回踩20日线」是作者复制模板的笔误，与本系统的 `zhangting20`
> 无关；两个流派的条件和目标完全不同。

**为什么 `CROSS` 要三条同时成立**：这要求昨天收盘同时位于 5/10/20 日线之下、今天一根阳线
把三条线一起收复。三条线必须在阳线幅度内**粘合**才可能做到 —— 这才是原文真正在找的形态
（均线粘合后的放量突破），也是七个条件里最稀缺的一个（1500 根里通常只有 10~20 次）。

**评分构成**：急跌结构 +6、距前高 ±2~+8（分「压力区内 / 突破区 / 太远 / 已越过」四档）、
反弹幅度 +6/+3/−8、5 日涨幅 +4/−6、量能 +6/+1/−4、均线共振 +12/+6/+3/−2、当日确认 +5/+1/−3。
结构分在无信号时封顶 +22（避免「有急跌背景」就等于偏多），有信号时放开到 +50；
八项同日成立再 +40，3 根内 +26，8 根内 +12。信号后**跌破信号 K 线最低价**直接压到 −12 以下。
另有一条兑现判断：信号后已涨超 12% 时不再给信号加分并提示「这一段走完了」—— 二买的利润空间
就是「急跌低点 → 前高」，走完再谈性价比没有意义。

**副图「二买位置」**：青色为开盘距前高 %（参考线 10），黄色为 5 日涨幅 %（参考线 8），
两条都是「不能过头」的约束，同轴可比。量比 1.5 与反弹 50% 的量纲差太多，只在文字里给。

**指数适配**：5% 与 3% 是绝对涨幅阈值，指数的日波动只有个股 1/3，实现时乘 `ctx.idxK`
（上证 0.24、创业板 0.75 左右），个股恒为 1、口径不变。条件本身按日线根数定义，
周月线上整个流派置灰（`DAY_STRUCT`）。

## SKDJ 超卖反弹（弱反弹不是底）

来源：用户实盘思路 —— **SKDJ 超卖后的那次反弹，弱反弹往往说明行情还没见底，强势反弹才值得做波段买入**。
这个判断的关键在于：超卖本身不构成买点，超卖之后「反弹的力度」才是。所以这个流派是双向的，
既标买点，也明确标「假底」。

**指标口径**（通达信 SKDJ）：`RSV(9)` → `SMA(·,3,1)` 得 K1 → 再 `SMA` 一次得慢速 K → D 对慢速 K 再平滑。
比 KDJ 慢一档，单根抖动被抹掉，正好用来判断「这一波反弹有没有力度」，而不是「今天有没有金叉」。

**事件模型**：一次「K 跌进 20 以下 → 低位金叉」= 一次反弹事件。金叉必须离谷底 20 根以内
（再远说明 K 早已修复完，那是高位波动，不是超卖反弹），同一次探底 8 根内只记一次。

对每个事件量化五个维度，加权成 0~100 的强度：

| 维度 | 满分 | 说明 |
|---|---|---|
| K 抬升 | 24 | 谷底 K → 阶段最高 K，≥30 点给满 |
| K 现位置 | 16 | 是否进入 50 以上的强势半区 |
| 价格涨幅 | 24 | **用当前涨幅，不用历史峰值**，10~20% 给满，>26% 反而扣（追高） |
| 量能 | 16 | 反弹段均量 ÷ 下跌段均量，≥1.3 给满，**<0.8 扣 8** |
| 收复 MA20 | 14 | 波段生死线，收盘站上才给满 |
| D 线上行 | 6 | K、D 同步才叫真反弹 |

再加三条修正：**跌破谷底 −18**（这一项就是「弱反弹 = 还没见底」在分数上的落地）、
**涨上去又回吐一半以上 −10**、**K 从高点回落且压到 D 之下 −8**。

**判定与分数**

| 状态 | 条件 | 分数 |
|---|---|---|
| 强势反弹 | 强度 ≥62 且 K ≥45 | +34 ~ +68 |
| 中性偏强 | 强度 45~62 | +8 ~ +42 |
| 弱反抽 | 强度 28~45 | −15 ~ +5 |
| 极弱 | 强度 <28 | ≈ −40 |
| 反弹熄火 | K 重新跌回 20 以下 | −45 |
| 破底 | 反弹过又跌破谷底 | −50 ~ −65（按破位深度分档） |
| 波段窗口过期 | 金叉距今超窗口 | 0（与当下无关） |

分数上限刻意压到 +68：这个流派回答的是「**现在能不能买**」，不是「这股强不强」。
同一个强度，第 5 根看到和第 35 根看到，买点价值完全不同 —— 所以另加位置衰减
（15 根 −8、22 根 −18、30 根以上 −28），并在解读里分成「初期 / 中段 / 后段」三种建议。

**跨周期**：K/D 是 0~100 归一化值，日/周/月共用一套超卖阈值（20/50/80），不需要按波动率折算。
但价格百分比阈值必须折算（`pxScale`：周 2.2、月 4.6），波段窗口也要按根数收缩
（日 40 / 周 25 / 月 16 根）—— 月线 40 根是三年多，那时的反弹与现在无关。

**副图「SKDJ(9,3,3)」**：橙色 K、蓝色 D，参考线 20 / 50 / 80。K 在 20~35 之间反复磨、
上不去 40，就是典型的「反弹力度不够」，一眼能看出来。

**主图**：绿点标超卖谷，金叉处标「★强反」或「弱反」，严口径破底（价格真反弹过 3% 又跌破）
标「破底」，未破底时画谷底低点的防守位虚线。

> 与「二买强势反击」的区别：二买找的是「急跌之后第一次反击」的时点，用的是跌幅、距前高、
> 5 日涨幅这些绝对百分比；SKDJ 这个流派判断的是「超卖之后的反弹够不够格」，
> 用的是 K 的抬升与量价配合。两者可以同时给信号，也可以一个说买一个说等。

## 威科夫操盘法（Wyckoff Method）

来源：Richard D. Wyckoff 1930 年代《Course of Instruction in Stock Market Science and Technique》。
核心不是形态，而是**「跟着复合人（Composite Man）的脚印走」**：大资金只能在横盘里悄悄吸筹，
吸够了才会拉升；出货同理。所以价格 + 成交量 + 所处阶段，三者缺一不可。

### 三大定律

| 定律 | 含义 | 本实现的度量 |
|---|---|---|
| 供需 | 买方力量 > 卖方 → 涨 | 上涨日均量 ÷ 下跌日均量（近 20 根） |
| 因果 | 横盘越久越高，上涨空间越大 | 用区间高度做横向投影（P&F count 的简化） |
| 努力与结果 | 量能是努力，价格进展是结果，背离预示转折 | 量比（V/MA20）对价格进展（涨跌幅/ATR） |

> 努力大而结果小（放量却不涨）发生在区间下半部 = **吸收（吸筹）**；
> 发生在区间上半部 = **派发**。同一个量价现象，位置不同含义相反，这是威科夫最容易被误读的地方。

### 五个阶段与事件

| 阶段 | 事件 | 判定（本实现） |
|---|---|---|
| A 停止下跌 | PS / SC / AR / ST | SC：跌 >4.5%、量 >1.6×、收盘回到当日 35% 分位以上。ST：回到 SC 低点 ±3.5% 内且量 < SC 的 75% |
| B 建仓 | 区间内反复 | 价格在支撑阻力间来回，穿越中轴 ≥4 次 |
| C 洗盘 | Spring / Test | Spring：盘中破下沿、收盘收回，且该支撑**此前被≥2 次触及未破**、发生在区间后段、量 <2.4× |
| D 转强 | SOS / LPS | SOS：涨 >2.5%、量 >1.6×、且穿越中轴或创 20 根新高。LPS：SOS 后缩量回踩守住上半区 |
| E 拉升 | BU | 收盘站上阻力 |
| 派发 | PSY / BC / UT / SOW | UT：上破阻力后收回、影线 >0.5 ATR、该阻力此前被≥2 次冲击未破 |

### 三个必须自己定死的参数

原文全靠肉眼，这三点是「同一张图两个人读出不同结论」的根源：

1. **区间怎么定** —— 窗口从 60 根起自适应扩张到 120 根，直到横盘结构被破坏。
   上下沿取窗口内最低价的 10% 分位 / 最高价的 90% 分位（抗单根插针）。
   区间成立要求：净位移 < 区间高度的 60%、**穿越中轴 ≥4 次**、高度占股价 8%~35%、
   且支撑/阻力各被触及 ≥3 次。
   > 只看「净位移小」是不够的：跌 30% 再反弹 20% 也是净位移小，但那是趋势不是横盘。
2. **Spring 凭什么算 Spring** —— 必须是对**已被验证的支撑**做假破。
   不加这条的话，任何一天盘中新低后收回都会被判成弹簧（实测 12 只股票 6 只是「弹簧已确认」，明显失真）。
3. **D 段要不要 LPS** —— 只要 SOS 就喊「突破前」是错误的，威科夫要求 SOS 之后还有缩量回踩（LPS）。
   本实现把「只有 SOS」单列为「D 段 · 强势待回踩」，信号强度低一档。

### A 股适配

| 差异 | 影响 | 处理 |
|---|---|---|
| 涨停板买不进 | SOS 若以涨停形式出现，实盘无法成交，封单也不计入换手 | 单独提示「涨停量价失真，入场等次日回踩」 |
| 连续跌停后打开 | SC 的量能常被恐慌盘放大失真 | 要求后续有缩量 ST 才认，单日巨量不单独定性 |
| T+1 | Spring 当日买入次日才能卖，若次日再跌无法止损 | 结论中强调「收盘必须收回区间内」，并要求随后的 Test |
| 游资 vs 机构 | 高换手更像游资接力，不是机构慢慢吸筹 | 换手 >15% 时扣分并提示「长期建仓前提打折扣」 |
| 吸筹周期更短 | 美股常压 6 个月，A 股 1~3 个月 | 窗口自适应 60~120 根 |
| 不能做空 | 派发阶段无法对冲 | UT/SOW 表述为「减仓离场」，不给做空目标位 |

### 评分构成

阶段（E 段 +16、D 段 +16、C 段 +18、B 段 +6、区间走弱 −8、派发 −22、下跌 −20）
\+ 事件（弹簧 +12、SOS +10、Test/LPS +8、SC/ST +5~8、UT −15、SOW −12、BC −10，区间不成立时统一打 3 折）
\+ 努力结果（比值 >1.25 加 10、<0.8 减 10）+ 量增价滞（按位置 ±6）+ A 股适配（高换手 −6）。

新增副图「努力 / 结果」：橙线量比、蓝线 `|涨跌|/ATR`，参考线 1.0（均量）与 2×。

## 威科夫 v2 · 三律合参（`wyckoff2`）

v1（`wyckoff`）已经能把「阶段 + 事件」读出来，但有三个盲点，实盘里都会咬人：

1. **只有区间边界，没有序列**。v1 知道「支撑在 6.68」，但不知道「低点是不是在逐级抬高」。
   而后者才是区分「吸筹」和「下跌中继」最硬的证据 —— 两者的区间形状可以一模一样。
2. **因果只有一个除法**。`res + rangeH` 的横向投影没有任何「磨了多久」的信息，
   磨了 40 根的区间和磨了 200 根的区间投出同一个目标。
3. **阶段是一句话，没有票数**。判断错了也没人知道错在哪一步，更不知道该盯什么才能证伪。

v2 不是 v1 的替代，是同一坐标系上的第二层：**结构计算放在 `public/js/shape.js`，
与选股页共用同一份实现**，所以全池扫描说「吸筹 C」，详情页精算不可能说「派发」。
两个流派可以同时开着看 —— v1 讲事件时间线，v2 讲序列与证据强度。

### v2 补的三件事

| 补的东西 | 怎么算 | 解决什么 |
|---|---|---|
| 摆动序列 | 2 左 2 右分形取最近 6 个高低点，统计「抬高 / 下移」次数（阈值 0.5%） | 高点下移 + 低点下移 = 供给主导，不靠猜 |
| 因果厚度 | 区间根数 ×0.3 + 边界测试次数 ×1.0 + 波动收敛度 ×20，封顶 100 | 区分「磨了 40 根」与「磨了 200 根」 |
| 证据投票 | 摆动序列 / 供需比 / 路径效率 / 区间位置四项独立投票，一致率即置信度 | 给结论配票数，低置信度就得说「证据不足」 |

顺带补了四个 v1 没有的事件：**震仓（shakeout）**、**跳过小溪（JAC）**、
**回踩溪边（BUEC）**、**无需求 / 无供给（ND / NS）**。

> 弹簧的时效窗口只有 25~30 根。放到 45 根会让「一个多月前测过、之后涨了 20%」的票
> 仍然挂在 C 段上 —— C 段说的是「弹簧刚被确认」，不是「历史上出现过弹簧」。

> 摆动点为什么取 6 个而不是 5 个：下跌结构常是「连续三个高点下移，然后反弹出一个新高」，
> 只留 5 个会把前面那段下移截掉，只剩「一涨一跌」——读出来是「走平」，也就是假中性。
> 600986 在 2026-11-17 就踩过这个坑：取 5 个点得到 1:1 判「走平」，取 6 个点得到 2:1 判「净下移」。

### 区间边界：用筹码带，不用分位数

v1 的上下沿用「窗口内最低价 10% 分位 / 最高价 90% 分位」。看着稳健，实际有个
系统性偏差：**自适应窗口永远从最新往回看**，所以下跌时当前价必然落在 10% 分位附近，
`posInRange` 于是恒为个位数。实测全池 3194 只主板，60% 的标的落在区间 15% 分位以下 ——
不是市场真跌成这样，是这个指标被定义钉死在了底部。

v2 改成 **成交量密集区**：窗口内价格分 24 档，按成交量寻峰，再从峰值向两侧扩展到
80% 量能为止（70% 太窄，会把带内的正常回撤误判成跌破），得到的上下界就是
「筹码真正换手过的价格带」。边界再 clamp 回窗口内真实的最高/最低价，避免分档取整外溢。

改成这样之后 `posInRange` 才有语义：

| 读数 | 含义 |
|---|---|
| 0~30% | 跌到筹码带下部，供给占上风 |
| 30~70% | 带内震荡 |
| 70~100% | 推向带子上沿，需求占上风 |
| **< 0** | **跌破筹码带** —— 威科夫说的 markdown 从这里开始 |
| **> 100** | **突破筹码带** —— E 段的起点 |

600986 在 2026-11-17 的读数是 `-1.1%`：80 根筹码带 6.74~8.12，收盘 6.72 比带下沿低 0.3%，
刚好跌到带子外面。
这个「刚好跌破」比任何形容词都清楚。

### 判定顺序：按证据的具体程度排，不按时间排

| 优先级 | 条件 | 为什么排在这 |
|---|---|---|
| 1 | 弹簧 + 缩量测试（25 根内）+ **价格回到区间中部**（30%~80% 分位） | 最具体的形态，证据链最长 |
| 2 | 弹簧出现但还没测试 | 缺一环，降一档 |
| 3 | SOS + 缩量回踩 + 守在区间上部（60%~110%） | D 段，要求两个动作都完成 |
| 4 | 只有 SOS，还没回踩 | 再降一档 |
| 5 | 收盘站上区间上沿 | E 段，比「吸筹」宽泛 |
| 6 | 区间上部出现上冲回落 / 买入高潮 | 派发 |
| 7 | 年内 25% 分位以下 + **跌破筹码带** + 60 根净跌 6% + 摆点净下移 | 宽泛兜底，四条同时满足才认 |
| 8 | 区间 35% 分位以下（含刚跌破带） | 走弱，跌幅还不够格叫下跌段 |
| 9 | 低点净抬高 ≥2 次且近 20 根无 SOW | B 段建仓（近期放量破中轴就不叫建仓了） |

第 1 条那个「回到区间中部」是 v2 里最容易被忽略、也最关键的一条约束。
弹簧的定义是「假破」，假破之后必须**快速收回区间内**；只破低不回升，那是「又跌回去了」，
不是吸筹。v1 的注释里写过这条，v2 把它写进了判定条件本身。

### 因果测度是简化模型，不是 P&F 计数

威科夫原教旨用点数图（Point & Figure）数横向格子，本实现没有 P&F 图，
用「时间 + 边界测试 + 波动收敛」三件事合成一个 0~100 的**建仓充分度**。

这个数只回答「因够不够厚」，**不回答「果往哪边走」**：
横得再久，向下突破同样是它的果。所以卡片里不给「量度目标」，只给这个充分度，
以及两条明确的反证条件 —— 这比一个看起来很精确的目标价诚实。

### 评分构成

阶段（C 段 +34、D 段 +30、E 段 +18、B 段 +8、走弱 −12、派发 −26、下跌 −22）
\+ 摆动序列（低点净抬高/下移 ×3，高点 ×2，±12 / ±8）
\+ 供需比（`sr − 1` ×14）+ 路径效率（×10）
\+ 事件（弹簧 +8、SOS +7、震仓 +5、UT −9、SOW −8，按 45 根新鲜度线性衰减，封顶 ±18）
\+ 位置（年内 20% 分位以下 −4、88% 以上 −6）+ 置信度（高 +6 / 低 −6）
\+ 放量滞涨（低位且方向不偏空 +2/天，其余 −3/天，最多 3 天）。

两条防「分数被拉回去」的规则：

- **事件分与阶段方向冲突时打五折**。下跌段里的 SOS 多半是失败反弹，不能因为「最近有个强信号」
  就把一只破位股拉回中性。600986 的 11-05/11-06 两根放量长阳正是这种情形。
- **放量滞涨要看方向和位置**。同一个「4 倍量只涨 1.4%」，在区间底部且阶段不偏空时算吸收，
  在下跌段里就是有人趁反弹往外倒。

七成标的偏空，看着刺眼，但这个数字是**市场的数字，不是算法的数字**：
同一天全池 60 根涨跌幅中位数 **−11.7%**、250 日位置中位数 **10.8%**、46.6% 的标的

## SuperTrend（ATR 通道棘轮）

来源：小红书「经典策略图鉴 · SuperTrend，是怎么拿住趋势的？」（2026-11-12）

原文只有三句话：

> 价格上下各挂一条线，离价格 3 倍 ATR；收盘价升破上方的线翻多买入，跌破下方的线翻空卖出，次日开盘执行。
> 长处：线只往持仓方向收，趋势里拿得住。短处：窄幅来回时线被反复穿过，容易小亏一串。

### 真正起作用的不是那两条线，是棘轮

轨道本身很简单（`hl2 ± 3×ATR(10)`），关键在下一根的处理：

```
下轨 = 前收盘 > 前下轨 ? max(裸下轨, 前下轨) : 裸下轨
上轨 = 前收盘 < 前上轨 ? min(裸上轨, 前上轨) : 裸上轨
```

多头时下轨**只上不下**，价格回踩不破就继续拿 —— 这就是「拿得住」的机制来源，本质是一条会自己走的移动止损。
翻向判定必须用**上一根**的轨道：本根轨道已经跟着价格收缩，用本根去比永远不会被破。

### 实现口径

| 项 | 取值 | 理由 |
|---|---|---|
| ATR 周期 | 10（Wilder 平滑） | 与通达信/ TradingView 默认一致 |
| 倍数 | 3.0 | 原文明确写死 3 倍 |
| 翻向确认 | 收盘价 | 盘中穿越不算，避免尾盘拉回造成的假信号 |
| 执行 | 次日开盘 | 原文规则，正好与 A 股 T+1 同构 |
| 周/月线 | 同样 (10, 3) | ATR 已按周期放大，改倍数会让轨道贴住价格或翻转严重滞后，统一参数反而可比 |

副图「SuperTrend 距轨」画的是 `(收盘 − 轨道) / ATR`：0 是翻向临界，±3 是原文说的「离得太远」。

### 评分构成

方向 ±16 + 翻转新鲜度（≤3 根 ±14 / ≤8 根 ±8）+ 成熟度（≥20 根 ±7）+ 末端（≥60 根 ∓5）
\+ ADX（≥25 ±12 / <20 −12，权重按实测 13.75 个百分点差距给）+ 假翻转率（>50% −10 / <35% −5 / <20% +5）
\+ 距轨（≤1 ATR +6 / >3 ATR −8）+ 翻转量能（≥1.3 ±5）

### A 股适配

| 差异 | 影响 | 处理 |
|---|---|---|
| 涨停封板 | 翻转日涨停，次日大概率一字板买不到 | 翻转 ≤2 根且涨幅近涨停时 −4，提示只作观察 |
| 震荡市占比高 | 原文「小亏一串」在 A 股会被放大 | 用本标的近 250 根的**实际假翻转率**压分，而不是套经验值 |
| 不能做空 | 翻空只能空仓，不能反手 | 翻空表述为「减仓 / 空仓」，不给空头目标位 |
| T+1 | 隔夜跳空无法当日纠错 | 结论直接给出「翻向线」价位，作为次日可执行的止损 |

### 已知局限

假翻转率按「翻转后 ≤3 根又翻回」统计。这个阈值对日线合适，对月线偏严（月线 3 根 = 一个季度），
所以月线视图下假翻转率通常偏低，读数时要结合 ADX 一起看。

## 三指标共振（MACD + KDJ + RSI）

来源：小红书「汤财好瑟 · 三指标共振做T：一套看穿买卖点的方法」（2026-11-12）

> MACD 用红绿柱看趋势和动能；KDJ 里 J 值最灵敏，J>100 超买、J<0 超卖，金叉偏多、死叉偏空；
> RSI 看强弱，>80 偏热、<20 偏冷。三灯同亮果断，两灯一致小试，三灯打架不动、等清楚。
> 震荡市好用；单边涨容易卖飞、单边跌容易接刀。

### 三个灯怎么点

每个灯只输出 `+1 / 0 / −1`，方向统一成「支持做多」为正，加起来就是原文的三种状态：

| 灯 | +1（偏多） | −1（偏空） | 0（不表态） |
|---|---|---|---|
| MACD | DIF > DEA | DIF < DEA | 柱相对价格 <0.05%（金叉/死叉临界） |
| KDJ | J<0 超卖；或近 3 根金叉；或 K>D | J>100 超买；或近 3 根死叉；或 K<D | \|K−D\|<1.5 且 35<J<65 的缠绕区 |
| RSI | ≤20 偏冷；或 >60；或 40~60 内偏强 | ≥80 偏热；或 <40 | 40~60 中性；或 6 日与 12 日方向相反 |

**「打架」必须单独判定**：合成 `+1` 既可能是「两多一空」，也可能只是「一亮两哑」。
前者原文要求停手，后者只是信号弱。混为一谈会把观望位置说成买点，所以额外输出 `conflict` 标记；
打架时所有方向性加分一律跳过，只保留环境提示。

### 评分构成

合成 `±3` → ±34（同亮）、`±2` → ±16（两灯）、`±1` → ±7（单灯）
\+ 环境（ADX<20 震荡 +6；ADX>30 单边 ×0.75，按实测放宽）+ 极端 J（>100 −8 / <0 +8）+ 极端 RSI（±6）
\+ 本标的同亮历史胜率（≥60% +10 / ≤40% −10，样本 <4 次不下结论）+ 新鲜度（≤2 根 ±6）

### 为什么加「历史胜率」

原文只说了这套灯「震荡市好用」，但没说什么叫震荡、也没说失灵时怎么办。
所以除了 ADX 判定环境，还直接用本标的自己的历史算：**三灯同亮之后 3 根，方向对了多少次**。
同一套规则，有的票 62%、有的票 33%（反向），这个数字比任何经验阈值都直接。

样本口径只针对「三灯同亮」，当前若只是两灯，文案会明确标注「以下是三灯同亮的历史表现，仅供参考」。

### A 股适配

| 差异 | 影响 | 处理 |
|---|---|---|
| T+1 | 原文讲的是日内做 T，A 股当天买了卖不掉 | 明确写「用于已有底仓的波段 T 或次日开盘低吸」 |
| 单边市失效 | 原文自己承认会卖飞/接刀 | ADX>30 时信号强度按 55% 折算，并给出具体警告文案 |
| 涨跌停 | 极端超卖次日可能一字跌停，低吸无法成交 | 不作为硬性拦截，在结论中提示 T+1 风险 |

## PA 多周期（阿布价格行为 · 完整交易系统）

来源：小红书「爱华-温酒煮茶 · 阿布价格行为实战：如何构建完整交易系统？」（2026-11-12）

原文的系统：

> 日线筛选趋势，30 分钟确认结构，5 分钟寻找入场，风险管理贯穿全过程。
> 核心概念：MTR、Trading Range、Breakout、Follow-through、Opening Breakout、
> Reversal（双底/更高低点/下跌失败）、Always In Long。
> 买入之前必须确定止损位置，再根据可承受风险计算仓位。A 股 T+1，5 分钟信号买入当天也卖不掉，
> 更需要控制初始风险。

### 周期层级怎么落到本系统

原文用 日线 / 30 分钟 / 5 分钟。我们只有日 / 周 / 月，所以层级换成：

| 原文 | 本系统 | 作用 |
|---|---|---|
| 日线筛趋势 | **更大周期定方向**：日线视图看周线，周线视图看月线 | 一票否决项：方向不明或冲突就不开仓 |
| 30 分钟确认结构 | **当前周期定结构**：20EMA 环境 + K 线重叠度 + Always In | 趋势 / 交易区间二分 |
| 5 分钟找入场 | **最近 5 根定触发**：L1/L2、H1/H2、带跟进的突破 | 具体入场点 |
| Opening Breakout | **跳空 + 当日实体**（无分钟数据） | 近似判断开盘方向是否被跟进 |

周期长度可以换，逻辑不能换：「三个周期方向一致才动手」这条骨架原封不动。
所以 `bigTrend()` 会按当前视图自动上移一档 —— 在周线视图里拿周线和周线自己共振，多周期就成了摆设。

### 落地了哪些原文概念

| 概念 | 判定方式 |
|---|---|
| Trading Range | 20EMA 上方占比 38%~62% 且斜率 <0.25 ATR |
| Breakout + Follow-through | 突破 20 根新高后 1~3 根仍收在突破位之上（量比同时给出） |
| 突破失败 | 突破后 3 根内跌回突破位之下 → −6，明确写「多头陷阱，不追」 |
| MTR 主要趋势反转 | 三件事同时成立：前段见低点 → 其后 ≥2 根强多头趋势K线 → 收盘越过反弹高点。缺一条都不算 |
| Reversal（双底/更高低点） | 复用 L1/L2 数 K 线，要求回调中先有反弹再创新低，连续阴线不会被数成 L3 |
| Always In Long | 最近 3 根 ≥2 根强多头趋势K线且收在 20EMA 之上 |
| 止损先行 | 近 12 根低点外侧 0.3 ATR，且至少 0.5 ATR 缓冲（避免被日内噪音扫掉） |
| 按风险倒推仓位 | 单笔风险 1% → 仓位上限 = 1% / 止损距离；T+1 无法当日纠错再打七折 |

### 评分构成

大周期方向 ±20 + 当前周期环境 ±15 + 共振 ±10（冲突 −6/−4）+ 触发（L2 ±12 / H2 ∓12）
\+ 突破跟进 ±8 / 突破失败 −6 + MTR ±10 + Always In ±6 + 盈亏比（≥2R +5 / <2R −8）
− 止损过宽（>10%）−6 + 开盘突破 ±4

### 与「价格行为」流派（`albrooks`）的分工

| | `albrooks` 价格行为 | `pamtf` PA 多周期 |
|---|---|---|
| 视角 | 单周期结构识别：H1/H2/L1/L2、双顶双底、楔形、20 缺口 | 系统决策：周期共振、MTR、突破跟进、止损仓位 |
| 输出 | 「现在是什么结构、信号K线质量如何」 | 「这笔该不该做、做多少、止损在哪」 |
| 周期 | 当前视图 | 当前视图 + 更大一档 |
| 权重 | 1.25 | 1.30 |

两者共用 `paScan()` 的读数，不会出现「价格行为说 L2，PA 多周期说没触发」的自相矛盾。

### 已知局限

- **没有分钟数据**：原文的「5 分钟入场」「开盘突破」只能近似。日线上的 Opening Breakout 用跳空 + 实体判断，
  精度低于原文，文案里已标注是「日线近似」。
- **月线视图无更大周期**：系统没有季线，`bigTrend()` 会返回不可用，流派退化为单周期结构分析，
  结论里明确说明「少了上一级周期的确认，仓位要更轻、止损要更近」。
- **盈亏比的目标位是静态的**：取区间上沿或箱体量度，不随行情滚动更新。趋势加速时目标会偏保守。

### 实证检验：这三套规则在 A 股到底灵不灵

照搬原文是危险的 —— 原作者的样本是美股与指数，A 股有 T+1、涨跌停、散户结构，同一套规则可能完全失效。
所以三个流派落地后，用 `tools/backtest.py` 在本系统自己的行情上跑了一遍：

```bash
python3 tools/backtest.py --n 150      # 随机 150 只，日线 1200 根
```

口径（与前端完全一致，且都含真实约束）：

- SuperTrend：收盘翻多 → **次日开盘**买入；收盘翻空 → 次日开盘卖出；一字涨停当日剔除
- 三灯共振：三灯同亮多 → 次日开盘买入，持有 3 根收盘卖出
- 成本：双边 0.12%（佣金 + 印花税 + 滑点），不扣成本的短线结论没有意义
- 样本：142 只（随机抽样中上市不足 300 根的剔除），2021~2026，共 2137 笔 SuperTrend 交易、7144 笔三灯交易

#### 结果一：SuperTrend 的长短处被数据精确复现

| 分组 | 笔数 | 胜率 | 平均收益 | 盈亏比 |
|---|---:|---:|---:|---:|
| 全部信号 | 2137 | 33.1% | +0.04% | 2.03 |
| **ADX ≥ 25** | 745 | **60.4%** | **+8.45%** | 2.40 |
| **ADX < 20** | 842 | **15.0%** | **−5.30%** | 2.04 |
| 持仓 ≤ 5 根（被反复打脸） | 95 | 14.7% | −9.30% | 0.51 |
| 持仓 > 20 根（拿住了） | 1386 | 43.7% | +4.30% | 2.57 |

原文那两句话在这里是**量化事实**：拿住的（>20 根）平均 +4.3%，被反复穿过的（≤5 根）平均 −9.3%。
全样本胜率只有 33%，靠 2.03 的盈亏比把期望拉回水面 —— 这正是趋势跟踪的典型形态，不是「高胜率战法」。

**ADX 是两个世界的分界线**：≥25 时 +8.45%，<20 时 −5.30%，相差 13.75 个百分点。
所以系统里 ADX 的权重给到 ±12（最初的 ±8 明显低估），文案直接把这组数字写进去 ——
用户看到「ADX 21.7，历史期望接近打平」时，知道这不是形容词，是 2137 笔交易的统计。

#### 结果二：三灯共振的优势比原文描述的小得多

| 分组 | 笔数 | 胜率 | 平均收益 |
|---|---:|---:|---:|
| 全部同亮 | 7144 | 46.9% | +0.20% |
| ADX < 20（原文说好用） | 3014 | 48.6% | +0.26% |
| ADX ≥ 30（原文说失效） | 1665 | 44.1% | **−0.09%** |

方向与原文一致，但幅度远没有 SuperTrend 那么夸张：单边环境下只是**没有优势**（−0.09%），
不是「接刀亏大钱」。所以单边惩罚从最初的 ×0.55 放宽到 ×0.75 —— 按原文的情绪去打折，
会让一个只是「不灵」的环境看起来像「危险」环境，这是两种完全不同的决策。

#### 结果三：跟买入持有比，这些是「择时工具」不是「赚钱工具」

同期 142 只标的买入持有：均值 +21.48%、中位 −7.97%、正收益占比 45.8%。

也就是说，A 股这五年里，**一半以上的票拿着是亏的**，而 SuperTrend 在 ADX≥25 的片段里做到了 60% 胜率。
它的价值不在超越买入持有，而在于：把「必须全程暴露在风险里」换成「只在趋势成立时暴露」。

#### 必须说清楚的局限

- **样本内**：参数（10, 3）没有做样本外验证，也没有做参数敏感性扫描，结论只对这套参数成立。
- **未建模的摩擦**：停牌期间无法卖出、退市、涨跌停连续封板导致的滑点放大，都没有计入。
- **区间选择偏差**：2021~2026 的 A 股整体偏震荡，趋势跟踪的绝对收益会被压低；换到单边市结论会不同。
- **不构成建议**：以上是方法有效性检验，不是收益承诺。

## 三周期共振（月定空间 / 周定趋势 / 日定买点）

来源：小红书「日周月三周期共振趋势找买点原来如此轻松！」（2026-11-02）

原文全文只有四句：

> 1. 月线定空间，连续 2 个月在 20 线上
> 2. 周线看趋势，连续 2 周在 20 线上
> 3. 日线选买点，在周线趋势后选买点
> 4. 选前期周线有倍量堆量标的

评论区那句「成交量还差一点点，下午收盘应该可以＞前三天」是正文没写进去的第 5 条 —— 日线买点要有量能背书。没有量，前三层只是「位置对」。

### 三层怎么落地

| 层 | 原文 | 实现 | 数据要求 |
|---|---|---|---|
| 月 | 连续 2 个月收盘 > 20 月线 | `streak >= 2`，只数已收官的月份 | ≥24 根月线 |
| 周 | 连续 2 周收盘 > 20 周线 | `streak >= 2`，只数已收官的周 | ≥24 根周线 |
| 日 | 在周线趋势后选买点 | 收盘 > 20 日线，且触发三种买点之一 | ≥25 根日线 |
| 量 | （评论区补充） | 当日量 > 前 3 日均量 | — |
| 堆量 | 前期周线有倍量堆量 | 近 12 周 ≥2 周的量 > 前 4 周均量 1.8 倍 | — |

### 20 均线为什么能当「空间」用

20 月线 ≈ 40 个月 ≈ 3 年多的平均持仓成本。站上去并连续 2 个月，等于说「过去三年的套牢盘都解套了，上方没有密集抛压区」——原文说的「空间」是这个意思，不是涨幅空间，是**上方阻力的空间**。

20 周线是 100 个交易日的成本，20 日线是 1 个月的。三层其实是同一条「成本线」在三个尺度上的位置关系，这也是为什么原文只用 20 这一个参数，而不是给每层配不同周期。

### 两个实现上的关键决定

**① 连续根数只数「已收官」的周期。**
11 月中的月线还没走完，拿它算「连续 2 月」，月中一根阴线就把条件打回 1 个月，信号会随行情来回跳。所以 `streak` 只看已收官的周期，另外单独输出 `live`（本周期至今在不在线上）—— 那才是原文「提前量」的来源：本月守住，下个月初门槛就正式满足。

**② 固定用日线读数，再映射到当前显示周期。**
如果直接拿「当前周期」当输入，周线视图下就会用周线 MA20 去当日线用，月/周/日三层里有两层是同一个东西。所以 `TRICYCLE()` 永远读日线，再按日期映射到当前视图，切换周期不会改变结论。

### 三种日线买点

原文只说「选买点」。要能执行就得把「买点」定义清楚，这里落成三种：

| 形态 | 判定 | 实测均值 |
|---|---|---:|
| 放量启动 | 收阳 + 站上 20 日线 + 量 > 前 3 日均量 1.5 倍 | −0.03% |
| 缩量回踩企稳 | 最低价摸到 20 日线上方 2% 内 + 收盘站回 + 量 ≤ 1.2 倍 | −0.35% |
| 跳空倍量回踩 | 近 5 根出现「高开 0.5% + 量 > 2 倍」，当下回到 20 日线上方 0~4% | −0.75% |

「缩量」有下限问题：量缩到前 3 日均量的 0.3 倍，说明抛压枯竭、买盘也没来，不一定是好事。系统不设硬下限，但把量比直接显示在读数里，让人自己判断。

### 与 pamtf（PA 多周期）的分工

| | `pamtf` PA 多周期 | `tritf` 三周期共振 |
|---|---|---|
| 判断对象 | 结构：20EMA 环境、Always In、H1/H2、突破跟进、MTR | 位置：三层同一条 MA20 的站上 / 跌破 |
| 均线 | EMA20（判环境） | MA20（卡门槛） |
| 输出 | 该不该做、做多少、止损在哪 | 三层齐不齐、今天有没有买点 |
| 周期 | 当前视图 + 上一级 | 月 + 周 + 日，恒定三层 |
| 权重 | 1.30 | 0.75（见实证） |

两者共用 `paScan()` 与 `ind.tri3`，读数不会互相矛盾。

### 评分构成

月线门槛 +20（连续≥2）/ +6（仅 1 月）/ −24（跌破）+ 斜率 ±6
周线门槛 +16 / +5 / −18 + 斜率 ±5
日线站上 +8 / 跌破 −10 + 位置（0~3% +6 / >10% −8）
买点 +12（放量）/ +8（回踩）/ +4（跳空）+ 新鲜度衰减（当日 100%、≤2 根 75%、≤5 根 45%）
堆量 +2
上限 96，下限 −70

### A 股适配

| 差异 | 影响 | 处理 |
|---|---|---|
| T+1 | 买点当天买不到，只能次日开盘 | 结论里给「明天高开 >3% 就不追」的硬条件 |
| 涨停 | 买点日涨停，次日可能一字板 | 不挂隔夜单硬追，标为观察 |
| 不能做空 | 月/周空头时只能空仓 | 跌破一律表述为「减仓 / 空仓」 |
| 月线滞后 | 连续 2 月 = 少则 40 个交易日 | 明确「月线是守得住，不是买得进」 |
| 周线倍量 | 高位放量派发远比低位吸筹常见 | 堆量降为筛选项，仅 +2 |

### 实证检验：这套方法在 A 股到底行不行

用 `tools/backtest-tritf.py` 在 135 只随机标的、2021~2026、1200 根日线上跑了一遍，成本双边 0.12%，次日开盘成交，一字涨停剔除。

#### 三个对照

同一批信号，只换过滤条件：

| 组 | 含义 | 笔数 | 胜率 | 均值 | 盈亏比 |
|---|---|---:|---:|---:|---:|
| A | 三层门槛 + 日线买点（原文完整版） | 1919 | 24.9% | **−0.24%** | 0.92 |
| B | 只有日线买点，不看月周 | 7690 | 27.0% | **+0.06%** | 1.02 |
| C | 三层门槛，但没有买点 | 2183 | 25.1% | −0.22% | 0.93 |
| D | 随机日买入（基线） | 30019 | 40.1% | −0.08% | 0.94 |

A 没有优于 B，也没有优于 C。**月周过滤没有带来增量，日线买点也没有带来增量。**

#### 换退出方式也救不回来

唯一可能的问题是「止损太近」—— 买点在 MA20 上，止损也在 MA20，一个正常波动就打掉。所以换了三种退出：

| 退出 | 笔数 | 胜率 | 均值 | 中位持仓 |
|---|---:|---:|---:|---:|
| 跌破 MA20 | 1919 | 24.9% | −0.24% | 5 根 |
| 跌破 MA20 的 97% | 1238 | 26.3% | −0.23% | 12 根 |
| 跌破买点 K 线低点 | 1004 | 11.0% | −0.33% | 9 根 |

放宽止损只是把持仓拉长，期望没有变化。这不是退出规则的问题。

#### 唯一为正的口径：拿 60 根

| 持有 | 笔数 | 胜率 | 均值 | 中位 |
|---|---:|---:|---:|---:|
| 5 根 | 2742 | 45.5% | −0.28% | −0.57% |
| 10 根 | 1947 | 42.6% | −0.12% | −1.25% |
| 20 根 | 1343 | 42.6% | −0.42% | −1.91% |
| 60 根 | 717 | 41.0% | **+0.43%** | −4.15% |

60 根转正，但中位仍是 −4.15%：均值靠少数大赢家拉起来，典型右偏分布。这也解释了为什么「按 20 日线止损」会把利润全砍掉。

#### 堆量是负向的

| 分组 | 笔数 | 胜率 | 均值 | 盈亏比 |
|---|---:|---:|---:|---:|
| 前期有倍量堆量 | 1033 | 24.3% | **−0.91%** | 0.72 |
| 无堆量 | 886 | 25.5% | **+0.54%** | 1.21 |

原文第 4 条在 A 股是反的。周线倍量在这批样本里更多出现在高位派发，而不是底部吸筹。所以系统里这条只保留判定与提示，加分从 +8 降到 +2。

#### 为什么

1. **月线门槛本身就是滞后确认**：连续 2 个月站上 20 月线，意味着行情至少已经走了 2 个月，买点常落在波段中后段。
2. **买点与止损同源**：都在 20 日线附近，噪音必然先打掉止损。
3. **A 股的趋势持续性弱**：2021~2026 样本里买入持有中位 −11.7%，趋势跟踪的绝对收益天然被压低。
4. **成本占比高**：持仓 5 根、双边 0.12%，等于每笔要先赚 0.12% 才回本，而信号本身没有这个优势。

#### 那它还有什么用

同期 135 只标的买入持有均值 **+19.6%**（中位 −11.7%），而三层都满足的票后续 60 根均值 +0.43%。
换句话说：**它筛出来的是一批长期趋势向上的票，这批票本身的 beta 就是正的**；但用它在日线上决定「今天买不买」，数据不支持。

所以系统的定位是：**筛选器，不是信号**。权重压到 0.75，解读卡里每次都把上面这组数字摆出来 —— 用户看到「三层齐」时，有权知道它的真实胜率。

### 已知局限

- 样本区间偏震荡（2021~2026），换到单边市结论会不同；
- 没有做参数敏感性（20 是原文给的，没测 18 / 25 / 30）；
- 月线只有 130 根，样本早期无法判定「连续 2 月」，会被剔除；
- 不构成建议。

## 三把锁低吸（趋势中的回调，三重条件串联）

来源：桔子写指标 2026-11-13「三把锁低吸模型，低吸起涨点一键筛选」

原文给的是通达信条件选股公式，三把锁串成一条信号，外加一个活性门槛：

```
MOM:=C-REF(C,1);
MOMI:=100*EMA(EMA(MOM,6),6)/EMA(EMA(ABS(MOM),6),6);
BSIG:=IF(LLV(MOMI,3)=LLV(MOMI,7) AND COUNT(MOMI<0,2) AND MOMI>MA(MOMI,3),1,0);
RECENT:=COUNT(C/REF(C,1)>1.015,22)>=1;
SSIG:=FILTER(BSIG=1,4);
QDSIG:=RECENT AND SSIG;

MA20:=MA(C,20);
BBLO:=MA20-2*STD(C,20);
BBTCH:=L<=BBLO*1.04;
BBRISE:=C>REF(C,1) AND C>=BBLO*0.98;
BBBUY:=EXIST(BBTCH,4) AND BBRISE;

MA60:=MA(C,60);
NR60:=ABS(C-MA60)/MA60<0.05;
M60UP:=MA60>REF(MA60,1) AND MA20>REF(MA20,1) AND MA(C,5)>REF(MA(C,5),1)*1.2;
三把锁选股:QDSIG AND BBBUY AND NR60 AND M60UP;
```

### 原文有一处笔误，照抄选不出任何票

第三把锁的最后一项是 `MA(C,5)>REF(MA(C,5),1)*1.2`，意思是**5 日均线单日上涨 20%**。

实测 291 只票 / 308273 根日线：该条件只成立过 **9 次**（集中在停牌复牌、数据缺口这类异常处），
加上其余条件后，完整信号 **0 次**。

5 日线单日涨 20%，需要今日收盘价比 5 根前高出约一倍 —— A 股连续 5 个涨停也只让 5 日线抬升 12% 左右。
所以这是笔误，本系统按「5 日线上行」（`MA5 > REF(MA5,1)`）实现。
修正后信号密度变成每只每年 **0.27 次**，正好符合原文自己说的「条件苛刻，不一定天天有满足的」。

### 三把锁到底在说什么

三把锁听着是三个指标，其实是同一件事的三个必要面：

| 锁 | 原文条件 | 它真正在挡什么 |
|---|---|---|
| ① 动量底 | MOMI 近 3 日创近 7 日新低、近 2 日曾为负、今日上穿 3 日均线 | 挡「还在跌」——不许在下跌途中接 |
| ② 布林回踩 | 近 4 日最低价触及下轨 ×1.04 内，今日收涨且收盘 ≥ 下轨 ×0.98 | 挡「追高」——必须跌到便宜位置 |
| ③ 60 线多头 | MA60 / MA20 / MA5 同时上行，收盘距 MA60 < 5% | 挡「没趋势」——没有多头趋势，低吸就是抄底 |

少任何一把，含义就变了：缺①是接飞刀，缺②是追高，缺③是抄底。这就是它敢叫「低吸」的底气。

### 实现口径

| 项 | 取值 | 理由 |
|---|---|---|
| MOMI | `100·EMA(EMA(ΔC,6),6) / EMA(EMA(|ΔC|,6),6)` | 原文写死 (6,6)；归一化到 ±100，日/周/月同参数可比 |
| 布林 | 20 日，2 倍标准差 | 原文写死。STD 用总体口径（与全系统 BOLL 一致），与通达信的样本口径差约 2.6%，被 1.04 倍容差覆盖 |
| 活跃门槛 | 近 22 根内出现过 >1.5% 的单根涨幅 | 原文 `COUNT(...)>1`，用来剔除长期没资金关注的死票 |
| 信号去重 | 同一轮 4 根内只取第一次 | 原文 `FILTER(...,4)`。下跌途中动量会反复拐头，不去重会连喊 |
| 周/月线 | 幅度阈值按 √5 / √21 放大，回看根数收缩 | 「1.5% 涨幅」「距 60 线 5%」是日线口径，月线一根动 10% 是常态，照搬等于对所有票放行 |
| 执行 | T 日收盘确认，T+1 开盘买 | A 股 T+1，与原文「次日执行」同构 |

副图「MOMI 双平滑动量」画 MOMI 与它的 3 日均线：两条线的相对位置就是第一把锁的判据，比绝对值更重要。

主图上同时标两种信号：

- **三锁**（金色实心）＝ 三把锁全开，原文口径；
- **二锁**（淡金小点）＝ 只有布林回踩 + 60 线多头，跳过了动量底。

之所以把「二锁」也画出来，是因为回测显示它比三锁齐更好 —— 见下一节。

### 评分构成

第三把锁按四档给环境分：三线全上 +26 / 60+20 上而 5 线刚拐头 +14 / 只有 60 线撑着 +4 / 60 线转头 −20。
第一、二把锁各 +24 / +10，三锁齐再 +22。
质量微调：回踩深度（踩在下轨上 +6，跌穿 4% 以上 −5）、动量起点（从 <−40 拐头 +6）、
量比（0.9~2.2 +4，>3 −4）、距 60 线（0~2% +4）、布林带宽（<8% −4）。

第一把锁只给 10 分（而不是 24），是回测结论直接反映到权重上，理由见下。

### 实证检验：三把锁在 A 股到底有没有用

样本：随机 300 只（有效 291 只），2021~2026，平均 1124 根日线，**360 笔信号**。
口径：T 日收盘确认、T+1 开盘买、双边成本 0.12%、一字涨停剔除。

**四种退出**

| 退出 | 笔数 | 胜率 | 均值 | 中位 | 盈亏比 | 持仓中位 |
|---|---|---|---|---|---|---|
| 收盘跌破 MA60 | 348 | 20.4% | −0.23% | −2.40% | 0.91 | 5 根 |
| 跌破 MA60 的 97% | 331 | 16.6% | −1.68% | −4.91% | 0.64 | 14 根 |
| 收盘跌破信号 K 线低点 | 329 | 15.5% | **+0.38%** | −4.14% | 1.08 | 12 根 |
| 收盘跌破（低点 − 1 ATR） | 320 | 19.7% | −0.10% | −6.31% | 0.99 | 20 根 |

**换成样本就翻号** —— 第一次用 117 只跑，「跌破 MA60」是 +0.83%；扩到 291 只变成 −0.23%。
这说明三锁齐这条信号本身没有稳定的正期望，正负取决于抽样。

**固定持有**

| 持有 | 笔数 | 胜率 | 均值 | 盈亏比 |
|---|---|---|---|---|
| 3 根 | 356 | 46.3% | +0.02% | 1.02 |
| 5 根 | 355 | **50.1%** | **+0.27%** | 1.15 |
| 10 根 | 349 | 42.4% | −0.01% | 1.00 |
| 20 根 | 333 | 39.3% | −0.88% | 0.80 |
| 60 根 | 306 | 42.8% | −0.33% | 0.95 |

唯一稳定为正的是**持 5 根**（胜率 50.1%、+0.27%）。持到 20 根反而 −0.88%。
换句话说：这套信号赚的是「反弹头几天」的钱，扛不住就变亏 —— 与原文「低吸起涨点」的定位一致，
但它也明说了这不是能拿住的买点。

**三把锁各自的贡献**（统一跌破 MA60 退出）

| 组合 | 笔数 | 胜率 | 均值 | 盈亏比 |
|---|---|---|---|---|
| A 三把锁齐全 | 348 | 20.4% | −0.23% | 0.91 |
| B 缺第三把锁（不管 60 线） | 6377 | 32.2% | −0.00% | 1.00 |
| C 只要动量底 + 60 线 | 468 | 23.1% | −0.12% | 0.95 |
| D 只要布林回踩 + 60 线 | 2487 | 26.6% | **+0.75%** | 1.33 |
| **D2 只去掉第一把锁，其余全保留** | **2454** | **26.4%** | **+0.74%** | **1.32** |
| E 只要第三把锁（趋势本身） | 4441 | 26.4% | +0.47% | 1.19 |

这是整套回测里最硬的一个结论：

> **第一把锁（动量底）是负贡献。** 把它删掉，信号量从 348 笔涨到 2454 笔（7 倍），
> 均值从 −0.23% 变成 +0.74%，盈亏比从 0.91 变成 1.32。

最可能的解释是时点：MOMI 上穿 3 日线的那一刻，反弹往往已经走了 1~2 天，
买进去正好是「反弹的第二天」；而「布林回踩 + 当日收涨」是反弹第一天，价格还在下轨上。
原文想用动量确认「止跌」，实际上把最好的入场点筛掉了。

第三把锁（趋势 + 距离）则是真正有用的过滤：没有它（B 组）均值归零，有了它才有 0.47%~0.75%。

**和「随便哪天买」比**

| 口径 | 笔数 | 胜率 | 均值 |
|---|---|---|---|
| 随机日买入，持 20 根 | 5418 | 46.4% | +0.48% |
| 三锁齐，持 20 根 | 333 | 39.3% | −0.88% |
| 同期买入持有（每只一次，4.6 年） | 291 | 48.1% | +33.10% |

三锁齐在 20 根尺度上**跑输随机买入**。同期这批票买入持有 +33.1% —— 说明选出来的确实是长期向上的票，
但「什么时候买」这件事，它没有提供正 alpha。

**距 60 线的分档**

| 距 60 线 | 笔数 | 均值 | 盈亏比 |
|---|---|---|---|
| 下方 0~5% | 27 | −0.93% | 0.13 |
| 上方 0~2% | 71 | −1.20% | 0.39 |
| 上方 2~3.5% | 108 | +2.36% | 1.83 |
| 上方 3.5~5% | 108 | −2.34% | 0.35 |

收窄到 0~3.5% 后整体 +0.95%（179 笔），比全样本的 −0.23% 好。
但分档内部 0~2% 是 −1.20%、2~3.5% 是 +2.36%，同一个「贴线」区间里差 3.5 个百分点 ——
这更像是少数极端值在拉均值，不是稳定的边缘。所以没有把它做成阈值，只在解读卡里提示。

**按年份**

| 年份 | 笔数 | 均值 |
|---|---|---|
| 2022 | 36 | −0.84% |
| 2023 | 118 | −2.19% |
| 2024 | 40 | +7.32% |
| 2025 | 102 | +0.64% |
| 2026 | 52 | −2.88% |

只有 2024 一年是明显正的，且中位仍是 −1.60%（靠少数大赚拉起来）。
2023 与 2026 是明确的负值。

### 所以系统里怎么用它

定位与三周期共振相同 —— **筛选器，不是买入信号**，但用法更具体：

1. 三锁齐把候选压到极小（全市场 4605 只，按 0.27 次/只/年算，平均每天约 5 只）；
2. 它的正期望只存在于「买后 5 根」这个窗口，第 10 根开始归零，第 20 根转负；
3. 所以买入后必须设硬止损（信号 K 线低点下方 1 个 ATR 或跌破 60 线），不能扛；
4. 想提高胜率，用「二锁」（布林回踩 + 60 线，跳过动量底）：信号多 7 倍、均值 +0.74%、盈亏比 1.32。

解读卡每次都把这组数字摆出来，权重给 1.15（与涨停回踩 20 日线同级）。

### 已知局限

- 样本区间 2021~2026 偏震荡，单边市结论会不同；
- 360 笔信号分到 5 个年份、4 个距离档，每格只有几十笔，任何单格结论都不稳；
- 没有做参数敏感性（6/6、20/2、60、5% 全是原文给的，一个都没调）；
- 原文的止损位没有定义，回测里的四种退出都是本系统补的，不是原文；
- 不构成投资建议。

## 数据说明

行情来自公开接口，多源分工并自动降级（`lib/sources.js`）：

| 用途 | 主源 | 备源 | 说明 |
|---|---|---|---|
| 日线 K 线 | 同花顺 `d.10jqka.com.cn` | 新浪 `quotes.sina.cn` | 同花顺为前复权，带成交额与换手率；新浪不复权、无成交额，只在同花顺缺数据（部分北交所）时启用 |
| 周 / 月线 | 由日线聚合 | — | 三源口径统一，不依赖上游是否支持周月 |
| 实时快照 | 腾讯 `qt.gtimg.cn` | 新浪排行 | 腾讯带量比与涨跌停价，指数同样可用 |
| 全市场列表 | 新浪排行 `Market_Center` | — | 5350 只 A 股，分页并行拉取 |
| 搜索 | 新浪 suggest | 腾讯 smartbox | 原名与简称都返回，指数带「指」标记 |

> 2026-11 起东财（`push2his` / `push2`）对所有请求返回空响应，线上实例同样不可用。这也是把取数拆成多源的原因：单点依赖会让整个系统在一次上游变更后彻底失效。

### K 线清洗（`lib/clean.js`）

上游给的数据并不总是干净的，而同花顺日线由「last.js（最近 140 根）+ 按年文件」拼成，拼接本身也会出错。清洗层在 `fetchDaily` 这个唯一入口跑一次，下游（指标、形态、选股精算）只认这一份结果。

**只做三件事，绝不补数据**

| 动作 | 规则 | 理由 |
|---|---|---|
| 修 | OHLC 收敛到 `[min(o,c), max(o,c)]` 包络 | 上游偶发 `high < open`，不修会让振幅、上影线算错；但**不动收盘价**，它是复权基准，改它会连锁污染全部指标 |
| 丢 | 非正价格、日期非法、结构不完整、同日重复 | 停牌占位行与字段错位都长这样，留着会污染均线 |
| 报 | 缺口、异常跳空 | 无法判断是停牌、除权还是缺数据，**交给人看，不自动填** |

缺失的交易日一律不插值、不用前值填充。假的连续比明显断层更危险：它让均线、形态、量能比一起失真，而且看不出来。

**缺口分层**（不依赖交易日历，用相邻 K 线间隔判断 —— A 股最长休市 12 天）

| 间隔 | 判定 | 处理 |
|---|---|---|
| ≤12 天 | 正常（周末 / 长假） | 忽略 |
| 13~90 天 | `suspend` 真实停牌（重组、ST、重大事项） | 记录，不告警 |
| >90 天 | `block` 疑似数据缺失 | 标记，`ok=false` |
| 跨年且 >300 天 | `year` 整年缺失 | 先自愈补拉，补不上才标记 |

**跨年整年缺失的自愈**：`last.js` 只回溯 140 根（约半年），更早的历史靠年份文件。年份接口对同一 IP 有限流，并发拉会随机丢一两个年份，而丢的是整整 242 根。所以年份文件串行拉（多花一秒），拉完再按「相邻日期跨度 >300 天」反查缺失年份补拉，最多 3 轮。

这个 bug 曾经真实存在：`needYears` 从 `nowYear - 1` 开始算，当年文件永远不拉，导致每年 1 月到 4 月中旬的 K 线整段消失 —— 2025-12-31 直接接 2026-04-17，看上去像单日暴跌 20%。清洗层上线时 `DATA_VER` 递增，把之前基于残缺序列算出的形态缓存全部作废重扫。

**质量信息的去向**：`/api/stock` 与 `/api/screen/klines` 返回 `quality`（`ok / gaps / jumps / droppedN / newListing`），详情页头条只在「整段缺失 / 已清洗行 / 数据不足」时亮黄色标记，鼠标悬停给出具体区间。停牌不提示 —— 每只重组过的票都弹一次就成了噪音。

### 独立通道校验（`tools/verify-tdx.py`）

主数据源是同花顺网页接口，新浪兜底 —— 两条链路都走 HTTP，上游改口径时页面上看不出来：图照样有 K 线，只是错了。
所以留了一条**完全独立**的对账通道：[tdxrs](https://github.com/jiangtaovan/tdxrs) 走通达信自有协议（TCP 7709），
与网页接口没有任何共用环节。

```bash
pip install tdxrs
python3 tools/verify-tdx.py                    # 随机抽 20 只
python3 tools/verify-tdx.py 600519 000001      # 指定标的
```

判定规则：差 >0.5% 的根数为 0 即一致；若**比值恒定**且集中在某日之前，是前复权口径差异；只有日期错位或缺口才是真问题。

实测结论（2026-11-13，24 只 × 250 根 = 5539 根）：

| 结果 | 数量 | 说明 |
|---|---|---|
| 完全一致 | 16 只 | 收盘价逐根相同，最新交易日也对齐 |
| 复权口径差异 | 5 只 | 601615 / 600057 / 605099 / 002287 / 300505，除权日**之前**存在 0.5%~0.7% 的恒定偏移，除权日之后完全一致 |
| 无重叠 | 1 只 | 920808（北交所），tdxrs 服务器返回空 K 线，属上游覆盖问题 |
| 需排查 | 0 只 | 无错位、无缺口 |

复权差异的原因是两家前复权的除权价折算方式不同（同花顺按除权参考价，通达信按分红再投），
不是数据错误。比值恒定意味着整段历史只是被**均匀缩放**，均线关系、ATR、形态全部不变，
所以没有切换数据源 —— 切换反而会让所有基于旧序列算出的缓存与结论失真。

这工具的价值不在「跑一次通过」，而在下次怀疑数据时能在 30 秒内给出结论，而不是靠肉眼比对几家网站。

**新股**：上市不足 30 个交易日的标的仍可打开看 K 线，但不出评分，解读卡直接写明「只有 N 根 K 线」，避免用 8 根数据算出「均线缠绕、方向待选」这种看起来像结论的噪音。


服务端缓存：日线 60 秒（收盘后 10 分钟）、全市场 60 秒（收盘后 5 分钟）、快照 8 秒；失败重试，上游返回空也重试。成交量单位统一为「手」。
盘中每 15 秒刷新自选股价格、每 20 秒刷新指数条、每 60 秒刷新当前 K 线。

当日 K 线在盘中是「半天成交量」，直接和 5 日 / 20 日均量比，每天上午都会得出「明显缩量」。盘面诊断与情绪温度按日内成交量的经验累计曲线（开盘半小时约占全天 22%，分上下午两段插值）折算回全天口径，收盘后不再折算。

所有指标、评分、价位与结论均由历史行情按固定规则计算，**不含任何模拟、随机或人工构造的数据**；选股结果同样来自真实行情，不满足条件的标的不会被「凑数」进列表。仅供技术分析方法演示，不构成投资建议。
