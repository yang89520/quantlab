怎么验证这份原型

1. 只用键盘走一遍。 Tab 从头到尾，每个可点元素都该有蓝色焦点环；在今日一页里打开抽屉后，Tab 不该跑到背后的页面， 按 Esc 关闭后焦点应回到触发它的那个按钮。

2. 缩到 320px。 不应出现横向滚动；七格变单列；观察池表格变卡片；按钮仍可点（≥44px）。

3. 切换数据状态。 今日一页底部的控制条切到「试用数据不完整」——看看结论变灰但内容仍在； 切到「三期未上线」——③ 时机格应显示"需策略实验室就绪"，而不是 0。

4. 打开系统的「减少动态效果」。 页面不该再有任何过渡动画。

5. 分析台的 40 个流派 Tab。 在搜索框输「MACD」应只剩匹配项；用 ← → 键在可见项之间移动，Home/End 跳首尾； 选中项会自动滚到可视区中间。

6. 选股器的漏斗。 五格数字必须能说明"从 5342 怎么筛到 47"；扫描按钮点下去要显示真实进度， 不许只有"加载中"三个字。
