## 2026-11-16 · 板块等权指数剔除超限单日样本

- 原值：无边界，任何单日涨跌幅都算进均值
- 新值：`sector.aggregate.maxDailyChg = 0.31`（单只成分股单日 |涨跌幅| > 31% 的样本剔除，价格照常推进）
- 依据：A 股单日理论极限是主板 ±10% / 双创 ±20% / 北交 ±30%，31% 以上只可能是
  除权未复权、复牌首日或脏数据。实测金融行业板块 `ret20` 曾算出 28502%
  （成因是 `000001` 在上交所是上证指数、在深交所是平安银行，两条序列被混取）
- 变更前 20 日命中率：不可比（此前对账 0 条，闭环未跑）
- 变更后 20 日命中率：见下一条
- 结论：保留

## 2026-11-16 · 首次回补 20 个交易日，闭环开始产出对账

- 原值：`prediction` 1 天、`reconcile` 0 条
- 新值：`prediction` 20 天、`reconcile` ≥ 18 条
- 依据：M1 里程碑要求「连续 5 个交易日有预判卡且有对账」。此前代码齐了但没有调度，
  库里永远只有一天数据，命中率画像无法计算
- 变更前 20 日命中率：不存在（分母为 0）
- 变更后 20 日命中率：见 `node tools/pred-report.js --days 20`
- 结论：保留。**这是本项目第一个真实可信的命中率数字**（无论高低）

## 2026-11-18 · 板块 K 线来源：成分等权聚合 → 通达信板块指数（部分）

- 原值：221 个板块全部由成分股等权聚合出 K 线（需本地 38.5GB 上游库）
- 新值：99 个板块改用**通达信板块指数**（880xxx）真实序列，122 个仍走等权聚合
- 依据：新浪/东财都不提供板块指数 K 线，本地聚合是云端部署的唯一死结。
  通达信协议直接给板块指数，且自带 `upCount/downCount`（涨跌家数）
- 变更前 20 日 A 档数：9 个（2026-11-18 采集，全聚合）
- 变更后 A 档数：5 个（2026-11-18 采集，99 指数 + 122 聚合）
- 结论：保留。分档变化的原因是等权聚合与真实指数的动量口径不同——
  指数含权重、聚合是等权，两者对「板块有多强」的判断本就不同。
  **历史 sector_strength 与新数据不可直接比较**，对比时以本条为界。

## 2026-11-18 · 全市场快照主源：新浪排行 → 通达信网关

- 原值：`market-snapshot` = `sina-quote`（新浪排行接口，5579 只，1.5 秒），字段含换手率与流通市值
- 新值：`market-snapshot` = `tdx-snapshot`（5583 只，8.1 秒 / 命中代码缓存 3.2 秒），
  **换手率与流通市值缺失，落 null 并标 `degraded: turnover_float_cap_missing`**
- 依据：新浪是单点，被限流就整条链断；tdx 多服务器可故障转移。成交额已逐只对账 5/5 精确一致，
  价格/涨跌幅/振幅同源同口径
- 变更前后对 `breadth` 的影响：同一交易日两源对照 breadth 差异 < 0.3pp（5583 vs 5579 只，
  差异来自 4 只北交所新股）
- 受影响功能：**选股器的换手率列变空**；环境判定、对账、板块强度均不读这两个字段，不受影响
- 结论：保留。若需要换手率，把 `config.sources.tdx.prefer` 设为 false 即回落新浪

## 2026-11-24 · 板块资金流接入新浪源（口径变更，历史不可比）

- 原值：`net-inflow` 在 2026-11 东财 f62 失效后无可用源，`sectors` 全部走
  「成交额 70% + 量能 30%」的**降级口径**，`degraded: net_inflow_missing`
- 新值：`net-inflow` 首选 `sina-moneyflow`（B 级，云端作业实装），
  按板块代码精确匹配，220/221 命中；`funds` 分项含真实主力净流入
- 变更前（11-23 及以前）：板块 `degraded = 221`，A 档 4~7 个
- 变更后（11-24 起）：`degraded = 1`，A 档 **9 个**
- **历史不可比，且无法回补**：新浪资金流接口没有日期参数，只返回「此刻」的值。
  历史日重算后 `netInflow` 仍为 null —— 这是数据源的客观限制，不是没做。
  拿今天的资金流写进过去就是前视偏差（D3），已在 `sectordata.collectDict` 与
  离线字典路径上双双拦住，并有日志 `inflow_stripped` / `inflow_skipped` 留痕。
- 结论：保留。对比判断力曲线时，以 **2026-11-24** 为口径分界；
  跨界的 A 档数量变化不代表市场变化。
